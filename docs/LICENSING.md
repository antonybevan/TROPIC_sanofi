# Licensing and source rights

This repository currently declares **no open-source license**. Public visibility on GitHub does
not grant permission to copy, modify, redistribute, or use the repository's code or documentation.
Reuse requires permission from the repository owner unless another written agreement applies.

The repository also contains or refers to material whose terms are independent of repository
ownership, including source clinical data, published literature, CDISC terminology, SAS/SASPy,
Pinnacle 21, and other vendor or standards content. Those terms govern access, redistribution,
and use of the respective material. Patient-level and licensed source data are intentionally not
distributed through Git.

If an open-source license is selected later, add the complete license text at the repository root
and update this document and the release notes together. Until then, do not describe this project
as MIT-, Apache-, or otherwise open-source licensed.
