## 1. What is being measured

This appendix quantifies the records that could be affected by the unresolved pain progression and palliative-radiotherapy rules. It does not decide which records qualify.

The current 37 pain-labelled records were produced by a non-conforming implementation that uses median analgesic score, a PPI increase threshold of 2, an absolute analgesic-score increase of 10, combined-component confirmation and a terminal-trigger exception. The protocol/corrected-publication rule instead requires component-specific visit summaries and confirmation under the [`F-042 Endpoint Approval Specification`](F042_ENDPOINT_APPROVAL_SPEC_2026-08-03.md). Consequently, the 37 records are a current-output inventory, not a clinically valid candidate set or an author-adoption denominator.

The counts are from the real MP arm. The reconstructed CbzP ADTTE is a separate synthetic demonstration layer and does not contain the same component-level provenance. No comparative inference is made here.

The broad `PRTRT contains radi` inventory is not a treatment-intent rule. Direct-intent source text produces a materially different source profile:

|---|---:|---:|---:|---:|

All 12 complete direct-intent CM start dates and all 3 direct-intent PR dates are post-randomization. The one undated direct-intent CM record has an end date but no start date and cannot enter the primary exact-date derivation.

The date-only comparisons are descriptive screens. Under the recommended author-decision rule, evidence after the protocol-required confirming visit does not backdate a primary pain event. Direct-intent RT remains a standalone criterion on its own complete start date.

## 4. Bounded event-count scenarios

The following range is a programming impact bound, not a statistical result:

| Scenario | Pain records retained as PFS events | Total PFS events | Required interpretation |
|---|---:|---:|---|
| Current sealed Path A output | 37 | 327 | Reproducible only; generated by the non-conforming candidate algorithm |
| Conservative all-excluded bound | 0 | 290 | 282 disease + 8 death; requires an author-adopted exclusion rule |
| Signed diary/RT re-derivation | Not inferable from 37 | Not inferable from current counts | Requires complete re-derivation because corrected diary rules may both remove and add events and RT can create new event dates |

The prior `290 + k` framing is no longer valid: the author-adopted rule can identify events outside the current 37 and can redate events. Regeneration must cover PFS/TTPAIN `ADT`, `AVAL`, `CNSR`, event descriptions, KM summaries, medians, hazard ratios, risk tables, figures, and all dependent reviewer metadata. Counts alone cannot predict the direction or size of a treatment-effect change.
